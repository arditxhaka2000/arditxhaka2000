## Fol Smart — chatbot SaaS

[AI-Chat-Web](https://github.com/arditxhaka2000/AI-Chat-Web-portfolio) · [Website](https://www.fol-smart.com/)

A platform where businesses configure a chatbot using their own products, FAQs and business information. It has a React/TypeScript dashboard, a Python/FastAPI backend and Supabase for authentication and data.

The work goes beyond generating replies: workspace isolation, Stripe billing, message quotas, leads, team access and Meta channel integrations are part of the application. The repository includes tests for billing, webhooks, delivery retries and dashboard flows.

## Plans to Space — building drawings and 3D review

[plans-to-space](https://github.com/arditxhaka2000/plans-to-space-portfolio)

An ASP.NET Core application for uploading building PDFs, processing them in background jobs and reviewing selectable 3D model drafts beside the original drawings. Python handles PDF/OCR and geometry processing; TypeScript and Three.js handle the viewer.

It keeps source evidence, notes and model revisions together. Automatic interpretation supports a limited set of drawings and records estimates and unresolved details. It uses local processing rather than an LLM.
